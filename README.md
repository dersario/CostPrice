# Себестоимость ингредиентов и рецептов

Локальное PWA для учёта ингредиентов, полуфабрикатов и расчёта себестоимости рецептов.

## Основные возможности

- **Справочник ингредиентов** с ценой за упаковку и автоматическим расчётом цены за единицу (`г`, `кг`, `мл`, `л`, `шт.`).
- **Перевод между измерениями**: для ингредиентов можно задать плотность (`г в 1 мл`) и/или вес одной штуки (`г в 1 шт.`), чтобы в рецептах свободно переводить массу ↔ объём ↔ штуки.
- **Быстрый ввод рецептов**: ингредиенты можно добавлять прямо в рецепте без предварительного заполнения справочника, указывая цену и её единицу измерения сразу или позже.
- **Полуфабрикаты (рецепт в рецепте)**: любой рецепт (например, крем, бисквит, начинка) можно включить в состав другого рецепта с защитой от циклических ссылок.
- **Масштабирование рецепта**: мгновенный пересчёт на коэффициент (`×N`), целевой вес/выход или под другой диаметр круглой формы (`Ø см`), с возможностью зафиксировать новый масштаб в рецепте.
- **Прямые затраты**: учёт труда (в том числе по формуле `часы × ставка в час`), упаковки/расходников и накладных расходов.
- **Гибкое ценообразование**: расчёт цены продажи по фиксированной наценке (`₽`), проценту наценки (`%`), целевой марже (`%`) или целевому фудкосту (`%`), с показом чистой прибыли и маржинальности.
- **Экспорт и резервные копии**: выгрузка технологической карты в CSV (Excel), печать / сохранение техкарты в PDF, полный экспорт и импорт базы данных в JSON.
- **Офлайн-работа и синхронизация**: данные хранятся локально в IndexedDB (Dexie); при желании включается автоматическая облачная синхронизация через Supabase с изоляцией рабочей области (RLS по заголовку `x-workspace-id`).

## Запуск локально

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
npm install
cp .env.example .env
npm run dev
```

Проверка тестов и продакшен-сборки:

```bash
npm test
npm run build
```

## Настройка Supabase (необязательно)

1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните содержимое [`supabase/schema.sql`](./supabase/schema.sql).
3. Скопируйте Project URL и публичный `anon` key в `.env`:

   ```dotenv
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-public-anon-key
   ```

4. В приложении откройте «Настройки», сгенерируйте или введите код рабочей области и нажмите «Подключиться».
